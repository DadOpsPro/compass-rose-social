# Scene stills

Put production photos here (`01.jpg` … `05.jpg`) and keep `renderer/examples/gsl-silent.json` `image.src` paths as `./assets/01.jpg` etc.

- Relative paths resolve from the timeline JSON file.
- Sandals themes = Sandals / UVI Sandals assets only. Beaches = Beaches only.
- Full-bleed 9:16 is applied automatically (`fit: "cover"`). Landscape photos are cropped, never letterboxed.
- Do not commit client photos unless they are already approved for this repo.

Until assets land, render the smoke timeline (public sample stills) or use `color:#1B4F72` as `image.src`.
